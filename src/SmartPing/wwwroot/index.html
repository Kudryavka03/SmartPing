指标说明

ICMP Ping
发送 ICMP Echo，可配置负载大小。超时时间固定为 2 秒。Windows 或目标防火墙可能阻止 ICMP。
TCP Ping
测量建立 TCP 连接的耗时。端口需要开放；连接拒绝及连接超时都记作失败。
丢包率
所选时段内，失败探测数占全部已完成探测数的比例。
疑似重传
仅用于 TCP：成功连接耗时大于设置阈值时标记。这是基于延迟的启发式判断，并非抓包得到的 TCP 重传次数。
平均延迟
概览、项目列表和图表均统计成功样本；TCP 疑似重传不计入均值，无符合条件的样本显示「—」。最小/最大延迟仍包含疑似重传样本。
抖动
同一节点连续两次探测均成功且有延迟值时，计算延迟差绝对值的平均数；TCP 排除疑似重传。失败、缺失延迟或 TCP 疑似重传会中断配对，不跨过这些样本比较。无有效配对显示「—」，延迟相同显示 0。

添加探测项目

为需要关注的主机或端口建立持续监测。

填写纯主机名或 IP，不包含 http://、路径或端口。

连接成功且耗时大于阈值时标记为「疑似重传」，属于延迟推断。阈值必须小于连接超时。
